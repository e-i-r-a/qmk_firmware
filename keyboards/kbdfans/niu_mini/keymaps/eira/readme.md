# eira layout

Modified QWERTY layout with number layer, symbol layer, navigation layer and function layer.

## Layer 0 / QWERY

The keys ESC and A switch to layer 3 when held.

The keys Z, X, C, V, M, COMMA, DOT, SLASH are "Mod-Tab" keys, so these modifiers are near to your fingers.

## Layer 1 / Numbers

Layer 1 gets the number keys on your home row.

## Layer 2 / Symbols

Layer 2 gets the symbols (shifted number keys) to your home row.

## Layer 3 / Navigation

Layer 3 is the navigation layer, with arows on H, J, K, L (like in vim)
and some other navigation keys logically arranged.

As I often use shift, ctrl and alt together with the arrow keys, they are positioned under the right hand fingers.

## Layer 4 / Function Keys

Layer 4 gets the function keys on your home row. As I am used to reaching upwards when using the funktion keys, I positioned them in the upper row too.
